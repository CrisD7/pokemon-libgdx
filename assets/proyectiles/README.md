# Imagen del ataque de Espeon

Coloca aquí tu imagen con el nombre exacto `confusion.png` (minúsculas).
Usa un PNG estático con fondo transparente, idealmente cuadrado y sin márgenes amplios.
Se dibuja a 24 × 24 unidades; no es una hoja de animaciones.

Ruta desde la raíz del proyecto: `assets/proyectiles/confusion.png`.
Reinicia el juego después de añadirla. Si falta la imagen, se usa el círculo violeta original.
Incluye el PNG en Git para compartirlo con los demás equipos.
